# StS2 Card Index

Slay the Spire 2 카드를 검색하고 확인할 수 있는 도감 어플리케이션입니다.

## 이번 버전에서 수정된 내역
- 카드 이미지를 webp로 전면 교체해서 최적화
- 모든 카드의 DB 추가 (괴짜 과학 제외)
- 희귀도 "고대의 존재"를 "고대"로 수정
- 카드 상세 페이지에서 화면 비율에 따라 배열 변경하여 편의성 향상
- 폰트 설정 추가. 시스템 폰트와 기본 폰트 중 사용 가능.
- 비용이 "사용불가"인 카드의 경우 특정 요소에서 비용을 숨김.
- 리젠트 별 X비용 추가
- 기타 시각적 자잘한 요소들 수정

## 주요 기능

- **카드 도감**
	- 카드 이미지, 이름, 색상, 종류, 희귀도, 비용, 효과 확인
	- 바둑판 또는 리스트 레이아웃 선택
	- 카드명, 비용, 종류, 희귀도 기준 정렬
	- 색상, 희귀도, 비용, 카드 종류 필터
	- 즐겨찾기 카드만 보기
	- 최근 변경된 카드만 보기
	- 멀티플레이 전용 카드 구분 및 표시
	- 카드 강화 정보 및 강화 효과 확인

- **카드 검색**
	- 카드명과 효과 문구 검색
	- 카드명에 한해 초성 검색 지원
	- 색상, 종류, 희귀도, 비용 필터
	- 멀티플레이 카드 포함 여부 선택
	- 검색 결과에서 강화 효과 일괄 보기

- **카드 상세 및 효과 표시**
	- 카드 기본 정보와 강화 정보 표시
	- 카드 효과에 포함된 키워드와 다른 카드 링크를 터치해 확인
	- 에너지, 별, 강화 수치 문법을 시각적으로 표시
	- 공용 시작 카드의 직업별 일러스트 지원
    - 일정 비율에서는 가로 특화 UI로 변경

- **카드 데이터 관리**
	- 카드 추가, 수정, 삭제
	- 카드 이미지와 강화 이미지 등록
	- 카드 색상, 종류, 희귀도, 비용, 별 비용 설정
	- 멀티플레이 전용, 최근 변경, 공용 시작 카드 지정
	- 기본 효과와 강화 효과를 별도로 입력
	- 쓰기 모드로 편집 기능 활성화 또는 비활성화

- **키워드 도감**
	- 키워드 목록 조회 및 초성 검색
	- 키워드 추가, 수정, 삭제
	- 키워드 숨김 및 숨김 키워드 표시 전환
	- 카드 효과에 키워드 표기 문법 일괄 적용

- **즐겨찾기**
	- 카드별 즐겨찾기 등록 및 해제
	- 즐겨찾기 상태를 기기에 저장

- **백업 및 복원**
	- 카드와 키워드 데이터를 JSON 파일로 내보내기
	- 커스텀 카드 이미지를 백업 파일에 포함
	- JSON 백업 파일 선택 후 데이터와 이미지 복원
	- 앱 내장 기본 데이터베이스로 초기화
	- 모든 카드의 최근 변경 태그 일괄 제거

- **환경설정**
	- 다크 모드, 라이트 모드, 기기 설정 따르기 지원
	- 설정과 데이터의 로컬 저장

## 준비 중인 기능
- 키워드 일괄 등록 때, 키워드에 해당하지만 [키워드] 문법을 적용시키지 않게 방지하면서 출력은 일반적인 텍스트로 출력하는 문법 #텍스트# 추가
- 카드 보상 시뮬레이터
- 덱 빌더 및 드로우 시뮬레이션
- 중복 카드명 등록 방지

## 확인된 문제
- 카드 만들기의 "카드 희귀도" 에 "토큰" 이 노출되지 않는 문제
- 추가로 필터에서 "토큰" 희귀도를 필터링할 수 없는 문제
